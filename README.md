## Description

This project uses **Keras/TensorFlow** to train a Convolutional Neural Network (CNN) that classifies traffic signs, and **OpenCV** to capture real-time video from a webcam and detect signs in front of the lens.

**Key features:**
- Training on a custom dataset (`myData/`)
- Image preprocessing (grayscale, equalization, normalization)
- Data augmentation to improve generalization
- Real-time detection with a configurable confidence threshold
- On-screen display of the predicted sign name and probability

## How to Use the Project

### 1. Clone the repository

```bash
git clone https://github.com/carlonox/traffic-sign-classifier.git
cd traffic-sign-classifier
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the model (optional)

```bash
python SeñalesdetransitoIAMAIN.py
```

### 4. Run real-time detection

```bash
python Test.py
```

## Project Structure

```
traffic-sign-classifier/
├── myData/                    # Custom dataset (one folder per class)
├── labels.csv                 # Class ID to sign name mapping
├── my_model.h5                # Trained model (generated by the training script)
├── SeñalesdetransitoIAMAIN.py # Model training and evaluation
├── Test.py                    # Real-time detection from webcam input
├── módulo1.py                 # Webcam capture test utility
├── requirements.txt           # Python dependencies

```
